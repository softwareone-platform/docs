# Configure auto-renewal for multiple subscriptions

You can use a single configuration order to enable or disable auto-renewal for multiple subscriptions within the same agreement.

This allows you to update auto-renewal settings for several subscriptions at once instead of creating separate configuration orders for each subscription.

### Before you begin

* The subscriptions must belong to the same agreement.
* Some subscriptions may not be eligible for the requested auto-renewal change. Eligibility is validated during the order process.

### Configure auto-renewal for multiple subscriptions

To configure auto-renewal for multiple subscriptions

1. Go to **Marketplace** > **Agreements**.&#x20;
2. Select the required agreement.
3. Select the **Subscriptions** tab. Then, review the current **Auto-renew** status for the subscriptions.
4. Select **Configure**.

<div data-with-frame="true"><figure><img src="../../../.gitbook/assets/image (35).png" alt=""><figcaption><p>Select <strong>Configure</strong> to update auto-renewal settings for multiple subscriptions.</p></figcaption></figure></div>

5. In the guided **Configure** flow, do the following:
   1. Select the required renewal option. Note that the available options depend on the vendor.
   2. Select the required subscriptions. Select **Next**.&#x20;
   3. Review the order details and optionally enter a reference ID or notes. Select **Next**.
   4. Review the order details. When done, select **Place order**.&#x20;
   5. Select **View order** to open the order details page or select **Close**.

After the order is submitted, the agreement status changes to **Updating** while the request is being processed. The selected subscriptions are updated according to the auto-renewal action requested in the configuration order.

# Change renewal policies for CSP subscriptions

You can update the renewal policy for multiple subscriptions under the same agreement through a single order.&#x20;

This allows you to apply the same renewal action to multiple active subscriptions at once. Available renewal actions include renewing subscriptions to a new term, extending the current service term, or canceling subscriptions at the end of their current term.&#x20;

The selected changes are submitted as a single configuration order and applied to all eligible subscriptions included in the order.

### Prerequisites

Only subscriptions under an active agreement can be updated.

### Change renewal policies for CSP subscriptions

To change renewal policies:

1. Go to **Marketplace** > **Agreements**.
2. Select the required agreement.
3. On the agreement details page, select the **Subscriptions** tab, then select **Configure**.

<div data-with-frame="true"><figure><img src="../../../../.gitbook/assets/image (34).png" alt=""><figcaption><p>Select <strong>Configure</strong> to update the renewal policies in bulk.</p></figcaption></figure></div>

4. In the guided **Configure** flow, do the following:
   1. Select the renewal option to apply, then select **Next**.&#x20;
   2. Select the active subscriptions to update, then select **Next**.
   3. Enter a reference ID and order notes, then select **Next**.
   4. Review the changes and select **Place order**.
   5. To open the order details page, select **View order**. Otherwise, select **Close**.

The configuration order is submitted for processing. Once processing is complete, the selected subscriptions are updated with the new renewal policy.

# Perpetual software

Perpetual software uses a one-time licensing model that allows you to use the purchased software indefinitely.

Unlike subscription-based software, perpetual licenses do not require recurring payments or renewals.

Organizations typically choose perpetual software when they:

* Require on-premises software deployments.
* Operate in environments with strict compliance or data sovereignty requirements.
* Prefer one-time purchases instead of recurring subscription costs.
* Need a specific software version for compatibility reasons.
* Want complete control over software updates and upgrade schedules.

### Supported products

You can order perpetual licenses for these products:

* Microsoft Perpetual Software - Commercial
* Microsoft Perpetual Software - Education
* Microsoft Perpetual Software - Charity

You can find these products on the **Catalog** > **Products** page.

### Ordering and licensing

Perpetual software orders are one-time purchases. After the purchase is completed, you retain the right to use the licensed software indefinitely, subject to Microsoft's licensing terms.

Perpetual software orders:

* Require a one-time upfront payment.
* Do not renew automatically.
* Do not require recurring subscription payments.
* Appear as one-time purchases on the agreement details page.

### Considerations

The following rules apply to perpetual software orders:

* License quantities cannot be increased or decreased after purchase.
* To purchase additional licenses, submit a new order.&#x20;
* After the order is completed and the license is provisioned, you can retrieve product keys from the [Microsoft admin portal](https://admin.microsoft.com). For details, see [Download software and product license keys](https://learn.microsoft.com/en-us/microsoft-365/admin/setup/download-software-licenses-csp?view=o365-worldwide#download-software-and-product-license-keys).
* Perpetual software purchases can be canceled within 30 days of the purchase date.

### Purchase perpetual software

You order perpetual software by submitting a purchase order.

1. Go to **Catalog** > **Products**.
2. Select the required **Microsoft Perpetual Software** product.
3. Complete the purchase process and create an agreement when prompted.

For detailed instructions, see [Buy perpetual software licenses](../additional-resources/perpetual-software/buy-perpetual-software-licenses.md).&#x20;

### Cancel a perpetual software order

You can cancel a perpetual software purchase within 30 days of the purchase date without incurring a termination fee.&#x20;

When a perpetual software purchase is canceled within the 30-day cancellation window:

* The associated software keys and download links are revoked.
* You are responsible for discontinuing use, uninstalling the software, and removing any downloads or links.
* The canceled item remains visible on the software details page in the [Microsoft Admin Center](https://admin.microsoft.com), but the activation key is disabled.&#x20;

To cancel a perpetual software purchase, contact [Marketplace Platform Support](../../../help-and-support/contact-support.md#contacting-marketplace-platform-support) and provide the order ID. We recommend that the cancellation request be submitted by an authorized representative of your organization.

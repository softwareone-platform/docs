# Granular delegated admin privileges

Granular Delegated Admin Privileges (GDAP) is a Microsoft security model that enables customers to grant service providers controlled access to Microsoft cloud environments. GDAP uses role-based access control (RBAC) to limit access to specific roles and resources for a defined period.

SoftwareOne uses GDAP to support customer environments while maintaining customer control over permissions and access.

### Benefits <a href="#why-is-gdap-important" id="why-is-gdap-important"></a>

GDAP helps improve security, governance, and support operations.

#### Benefits for customers

* GDAP allows SoftwareOne to respond to your technical needs faster.
* You define the level of access granted to SoftwareOne and can modify or revoke permissions when required.
* Role-based permissions help reduce security risks by ensuring access is limited to what is required.

#### Benefits for SoftwareOne

* More efficient support and issue resolution.
* Access that aligns with customer-defined security requirements.
* Improved operational consistency when delivering support services.

### Establishing GDAP <a href="#who-can-establish-gdap" id="who-can-establish-gdap"></a>

A GDAP relationship must be approved by a **Global Administrator** in your organization. Once approved, SoftwareOne can request and use only the permissions that have been granted.

### Impact of not implementing GDAP

Without GDAP, SoftwareOne may have limited ability to provide support and administration services efficiently.

#### For customers <a href="#for-your-business" id="for-your-business"></a>

* Support requests may require additional access approval steps.
* Issue resolution may take longer when access must be granted manually.
* Delays during critical incidents may affect business continuity.

#### For SoftwareOne <a href="#for-softwareone-as-your-service-provider-.1" id="for-softwareone-as-your-service-provider-.1"></a>

* More complex support and administration processes.
* Reduced operational efficiency due to manual access management.
* Additional administrative effort when supporting customer environments.

# Adobe discount codes

You can get lower prices on Adobe orders with flexible discount codes. This helps you see which codes are available to you, and how and when they are applied to your orders.

### Find your discount codes

To view your discount codes:

1. Go to **Marketplace** > **Agreements**.
2. Select the Adobe agreement.
3. Select the **Adobe** tab, then select **Discounts**.

The page lists every code available to you, including codes you have already redeemed.

### Discount code details

The following table describes the columns on the **Discounts** page:

| Column          | Description                                                                                                                  |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **Code**        | The discount code and its name. A label shows whether the code is **Active** or **Expired**.                                 |
| **Source**      | **Open** – a code from Adobe's promotions, available to eligible customers. **Closed** – a code set up specifically for you. |
| **Type**        | **Percentage**, **Fixed Discount** (a fixed amount off), or **Fixed Price**.                                                 |
| **Value**       | The discount, for example, 20% off.                                                                                          |
| **Valid**       | The dates the code can be used. Reusable codes also show **Discount lock until** and a date.                                 |
| **Order types** | The orders the code applies to: **Add seats**, **Renewal**, **Switch** (a mid-term upgrade), or **Any**.                     |
| **Redeemed**    | Whether you have already used the code.                                                                                      |

Open codes are updated from Adobe every day.

### Single-use and reusable codes

* **Single-use codes** can be used once. After you redeem a single-use code, it is not offered again.
* **Reusable codes** can be used on later orders until the date shown after **Discount lock until**. After a reusable code's end date, it is offered only if you already hold it.

### How discount codes are applied

The following table describes how discount codes are applied to each type of order:

| Order                            | How codes are applied                                                                                                                                                                                                                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Buy products or add licenses** | The code that gives you the lowest price is applied automatically. There's nothing you need to do.                                                                                                                                                                                          |
| **Renew late**                   | The code that gives you the lowest price is applied automatically.                                                                                                                                                                                                                          |
| **Renew in the renewal wizard**  | You choose a code for each item on the **Promotions** step. Codes you already hold are marked **Inherited** and selected for you. For more details, see [Renew Adobe subscriptions at your anniversary date](../renew-subscriptions/renew-adobe-subscriptions-at-your-anniversary-date.md). |
| **Upgrade a subscription**       | On the **Promotions** step, the code that gives you the lowest price is pre-selected. You can choose another or enter your own. For more details, see [Upgrade Adobe subscription](../manage-subscriptions/upgrade-adobe-subscription.md).                                                  |

Each code is confirmed with Adobe before your order is placed. When a code is applied automatically and Adobe refuses it, the next best code is used. If Adobe doesn't confirm any of your eligible codes, the order goes ahead without a discount.

Only one discount code can be applied to each item.

### Enter a code yourself

In the renewal and upgrade wizards, you can type in a code that is not on your list. If the code is not known, the wizard warns you. You can still place the order, but an invalid code causes the order to fail. To have a code added to your list, contact your SoftwareOne sales team.

### Why a code is refused

If Adobe refuses a code, the wizard shows the reason for each item. The following table describes the most common reasons:

| Reason shown                                                              | What it means                                                       |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| This discount requires the customer to already own a qualifying product.  | You need to own a specific product before you can use the code.     |
| This discount applies only to products the customer does not already own. | The code is for new products only.                                  |
| This discount is limited to a customer segment this customer is not in.   | The code is for another segment, such as Education or Government.   |
| This discount does not apply to this type of order.                       | The code is for a different order type, for example, renewals only. |
| This discount requires the renewal to keep the current seat count.        | Renew the same number of licenses you hold now.                     |
| This discount requires a different order quantity.                        | Change the quantity to one the code allows.                         |
| This discount requires a 3-year commitment this customer does not have.   | The code is for customers with a 3-year commitment.                 |
| This code is not known to Adobe.                                          | Check the code, or choose another.                                  |
| Only one discount code can be applied to a line.                          | Keep one code for the item.                                         |

If you're not sure why a code was refused, contact your account manager. For other messages, see [Common error messages](../common-error-messages.md).

# Why is my Adobe order still in Processing status?

Most Adobe orders complete within minutes, but some take longer. While an order is in **Processing** status, the agreement shows **Updating**, and you cannot place another order for it.

An order can stay in **Processing** status a little longer when:

* **Adobe is still completing its part of the order.** The SoftwareOne Marketplace checks the order again regularly until Adobe confirms it.
* **The order returns licenses from several orders.** Returns are placed one after another, so each one has to complete before the next starts.
* **Adobe is temporarily unavailable.** The order is retried automatically.

You don't need to do anything. The order completes automatically, or shows an error if it cannot be completed.

If an order is still in **Processing** status after its **Order processing deadline**, typically 30 days after it was placed, it fails. Contact SoftwareOne if an order is in **Processing** status for more than a few days.

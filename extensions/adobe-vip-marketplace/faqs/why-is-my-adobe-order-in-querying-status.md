# Why is my Adobe order in Querying status?

An order moves to **Querying** status when it needs an action from you before it can continue. The order's **General** tab explains what is needed.

The following table describes the most common reasons and what to do:

| Reason                                                                                                                               | What to do                                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Your 3-year commitment invitation is waiting.** While an invitation is waiting for your acceptance, orders for your account pause. | Accept the invitation in the Adobe Admin Console, then select **Process** on the order. For more details, see [How do I accept my 3-year commitment invitation?](how-do-i-accept-my-3-year-commitment-invitation.md). |
| **Your education sub-segments are not selected.** Adobe needs them for Education accounts.                                           | Select your sub-segments in the Adobe Admin Console, then select **Process** on the order. For more details, see [How do I select my education sub-segments?](how-do-i-select-my-education-sub-segments.md).          |
| **Adobe rejected your company name, address, or contact details.**                                                                   | Correct the field named on the order, then select **Process**.                                                                                                                                                        |
| **The agency type is missing** (Large Government Agencies).                                                                          | Select **Federal** or **State**, then select **Process**.                                                                                                                                                             |
| **Your VIP membership number could not be used** (migrations).                                                                       | Check and correct the membership number, then select **Process**. If Adobe is still migrating the account, wait and try again later.                                                                                  |

### Order processing deadline

An order waiting in **Querying** status doesn't fail because of its **Order processing deadline**. The deadline is cleared while the order waits, and a new one is set when you select **Process**. Complete the action the order asks for as soon as you can, so that your order goes ahead without delay.

For more details, see [Common error messages](../common-error-messages.md).

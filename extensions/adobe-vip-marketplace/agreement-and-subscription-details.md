# Agreement and subscription details

You can see the details of your Adobe account on your Adobe agreements and subscriptions in the SoftwareOne Marketplace. This helps you check your anniversary date, your quantities, and your 3-year commitment without opening the Adobe Admin Console.

These details are updated from Adobe regularly. The **Last Adobe sync date** shows when they were last updated.

### Agreement details

To see the details of an agreement, open the agreement and select the **Parameters** tab. The following table describes the main details:

| Detail                          | Description                                                                                                                                 |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **Adobe account setup**         | How the Adobe account was set up: new, migrated from Adobe VIP, or transferred from another reseller.                                       |
| **Company name**                | The legal name on the Adobe account.                                                                                                        |
| **Company address**             | The address of the company buying Adobe products in this region.                                                                            |
| **Primary Adobe administrator** | The primary administrator and contract owner of the Adobe account.                                                                          |
| **Adobe customer ID**           | The identifier Adobe assigned to the account.                                                                                               |
| **Adobe anniversary date**      | The date your subscriptions renew. It is normally 12 months after your first order, but can be up to 36 months with extended terms.         |
| **Order processing deadline**   | The date by which the current order must complete, typically 30 days after it was placed. An order still in progress after this date fails. |
| **Last Adobe sync date**        | When the agreement was last updated from Adobe.                                                                                             |

#### 3-year commitment details

The following table describes the 3-year commitment details on the agreement:

| Detail                                                                                                                                                              | Description                                                                                                                      |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **3-year commitment active**                                                                                                                                        | Shows **COMMITTED** when your 3-year commitment is active. Empty if you don't have one.                                          |
| **3-year commitment start date** and **3-year commitment end date**                                                                                                 | When your current commitment started and when it ends.                                                                           |
| **Minimum committed licenses** and **Minimum committed consumables**                                                                                                | The minimums of your active commitment.                                                                                          |
| **3-year commitment request status**                                                                                                                                | The status of a commitment invitation, for example, **REQUESTED** or **ACCEPTED**. This is not the same as an active commitment. |
| **Commitment request minimum licenses**, **Commitment request minimum consumables**, **Commitment request start date**, and **Commitment request end date**         | The details of a pending commitment request. They are empty when no request is pending.                                          |
| **3-year recommitment request status**                                                                                                                              | The status of an invitation to recommit for another 3 years.                                                                     |
| **Recommitment request minimum licenses**, **Recommitment request minimum consumables**, **Recommitment request start date**, and **Recommitment request end date** | The details of a pending recommitment request.                                                                                   |

You can also see your 3-year commitment on the **Adobe** tab. For more details, see [The Adobe tab](the-adobe-tab.md).

#### Linked membership and global customer details

| Detail                                                                                                                                                | Description                                                                                                                                              |
| ----------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Linked membership ID**, **Linked membership name**, **Linked membership type**, **Linked membership role**, and **Linked membership creation date** | The details of a linked membership, if your account is part of one. The type is **STANDARD** or **CONSORTIUM**, and the role is **OWNER** or **MEMBER**. |
| **Adobe global customer**                                                                                                                             | Whether the account is set up as a global customer.                                                                                                      |
| **Global customer deployment ID (this agreement)**                                                                                                    | The deployment this agreement belongs to.                                                                                                                |
| **Global customer deployments**                                                                                                                       | All deployments of the Adobe account, with their country codes.                                                                                          |

### Subscription details

The following table describes the details on each Adobe subscription:

| Detail                   | Description                                                                                                                                                             |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Adobe SKU**            | The full Adobe product code, including the discount level.                                                                                                              |
| **Renewal date**         | When the subscription renews.                                                                                                                                           |
| **Current quantity**     | The number of licenses you hold now.                                                                                                                                    |
| **Renewal quantity**     | The number of licenses that will renew on your anniversary date. It can be different from the current quantity, for example, after a reduction that applies at renewal. |
| **Last Adobe sync date** | When the subscription was last updated from Adobe.                                                                                                                      |

Each subscription also shows a short description of its current state, for example, that it will renew with a given quantity, that it expires on your anniversary date, or that it starts on your anniversary date.

### Why details change without an order

The SoftwareOne Marketplace regularly checks your Adobe account and updates your agreements and subscriptions to match. For example:

* Quantities are updated if licenses were changed in the Adobe Admin Console.
* Prices are updated when a 3-year commitment starts or ends, or when your agreement renews.
* Subscriptions that have expired or are inactive at Adobe are terminated.

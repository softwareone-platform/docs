# Renew Adobe subscriptions late

You can renew Adobe subscriptions that expired on your anniversary date for up to 14 days afterwards. This helps you get your licenses back if your subscriptions didn't renew, for example, because auto-renewal was turned off.

To renew late, you order the same products again. The SoftwareOne Marketplace recognizes the order as a late renewal.

### Prerequisites

* It is no more than 14 days after your anniversary date (US Pacific time). For more details, see [Key dates and deadlines](../key-dates-and-deadlines.md).
* You order products you had in your previous term.

### Renew late

{% stepper %}
{% step %}
**Start the order**

To start the order:

1. Go to **Catalog** > **Products**.
2. Select the Adobe product, for example, **Adobe VIP Marketplace for Commercial**.
3. Select **Buy now**.
{% endstep %}

{% step %}
**Order the same products again**

In the guided purchase flow, complete the following steps:

1. **Select agreement** – Select the agreement the subscriptions belonged to, then select **Next**.
2. **Select items** – Select **Add items**, add the products that expired, and enter the quantities you need under **New qty**. Then select **Next**. You can order more licenses than you had before.
3. **Details** – Add the reference details for the order, then select **Next**.
4. **Review order** – Review the order details, go through the terms and conditions, then select **Place order**.
5. **Summary** – Select **View details** to open the order details page, or select **Close**.
{% endstep %}
{% endstepper %}

You can also renew late with a new purchase for the same Adobe account.

### Next steps

Your order is processed as a late renewal. The licenses you had before are renewed, and any extra licenses are added at the same time. The best eligible discount code is applied automatically. When the order completes, your licenses are available again.
